The server exposes an embeddable lifecycle without global logging initialization. Its owned supervisor retains indexing and HTTP connection tasks after observer cancellation. Command permits are held until child kill/wait and private-input cleanup finish. The desktop lifecycle retains its library claim until that cleanup ends; repeated Tauri exit requests remain blocked until completion. Operating-system filesystem threads still retain their own handles/permits if a syscall stalls.
