# Hito documentation

Hito is in development and has no public release yet. The [roadmap](roadmap.md) shows what works today and what comes next.

## Use Hito

- [Getting started](guide/getting-started.md): your first account, your first music and your first plugin.
- [Your library](guide/library.md): music folders, albums and artists, and editing track details.
- [Plugins](guide/plugins.md): connect plugins, choose which sources play first, and find audio for any track.
- [Playlists](guide/playlists.md): make, import, follow and download playlists.
- [Listening](guide/listening.md): the queue, Now playing, lyrics and Discover.
- [Podcasts and audiobooks](guide/podcasts-and-audiobooks.md).
- [Your account](guide/account.md): password, signed-in devices, profile, screen lock and history.
- [Phone and desktop](guide/apps.md): install Hito on a phone, and the desktop app.
- [Administration](guide/administration.md): accounts, library access and offering plugins.

## Run a server

- [Self-hosting](self-hosting/README.md): start Hito and its plugins, and fix common problems.
- [Operations](self-hosting/operations.md): backups, restores, upgrades and network access.
