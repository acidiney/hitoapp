## Current behavior

Core owns identity, catalog, collection transactions, indexing and private SQLite storage. HTTP adapters authenticate through the shared extractor and map typed capability requests and results. Actual Rust routes generate OpenAPI and TypeScript. React pages use workflow hooks for async work; playback position updates do not rerender catalog pages. See [architecture decisions](architecture-decisions.md) and [interface direction](../DESIGN.md).

The library supports multiple server music folders, independent scans and removal/reconnection. Recording identity is separate from tagged-file checksums. Artist and album pages use exact library-scoped credits, release appearances, tagged order and scoped artwork. Personal recording and album title/artist edits retain source provenance and remain private. Development setup launchers generate read-only Docker mounts from native folder selections. Automatic desktop discovery and live platform setup acceptance remain open. See [folder behavior](music-folders.md) and [catalog browsing](catalog-browsing.md).

Personal HTTP plugin connections support administrator-offered addresses, manifest review, encrypted optional credentials, search, durable owner-only adoption and bounded authenticated audio relay. Discover can search, page, save and play provider recordings, including recordings without releases. Source-only refresh and bounded browser/native recovery recheck live authority. Debrid preparation, source preferences and complete recovery acceptance remain unfinished. See [plugin contracts](plugins.md).

Generic attribution, backlinks, persistence restrictions and live-provider checks remain necessary before offering it to accounts. It is not part of the normal deployment. See [Jamendo verification and limits](plugin-jamendo.md).

The separate community crate owns reporter provisioning, durable successful-playback receipts and candidate-only rankings in its own SQLite store. Three public-boundary regressions cover restart/replay and state ownership during unsafe ancestry or failed SQLite startup. The optional pinned-driver extension passes twelve selected core cases, all 38 folder-plugin cases and five server lifecycle/download cases, with strict all-target Clippy.
