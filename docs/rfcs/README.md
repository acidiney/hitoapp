# Design proposals

These RFCs propose architecture changes. Each has the status Proposed: nothing here describes current behavior, and none has been built. Each states a problem with evidence from the current tree, constraints, two or three options, a recommendation, a commit plan, test impact and open questions for the owner.

| RFC | Topic | Status |
| --- | --- | --- |
| [0001](0001-provider-source-lifecycle.md) | Provider source lifecycle as one module | Proposed |
| [0002](0002-playback-access-boundary.md) | Separate podcasts and downloads from Catalog | Proposed |
| [0003](0003-page-read-models.md) | Inertia page assembly into core read models | Proposed |
| [0004](0004-host-and-sync-client-identity.md) | Host identity and sync client identity | Proposed |

Read [architecture](../architecture.md) and [testing](../testing.md) first. Line numbers in the evidence refer to the tree when the RFC was written and drift as code changes.
