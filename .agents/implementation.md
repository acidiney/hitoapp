## Standalone desktop host

The first Tauri development host is `crates/hito-desktop`. It runs the shared UI against its own in-process backend and SQLite library. Native application paths choose private data storage and the Music grant without `HITO_MUSIC_FOLDER`. The user currently connects Music through Settings. The host has no remote-page mode, native IPC permissions, additional native folder dialog, or automatic scan yet. Its current playback is the shared browser adapter. `hito-audio` now supplies owned-file Symphonia decoding and optional CPAL output, with its own device tests. It is not connected to the host. Core now issues session-bound PlaybackSource grants with live expiry, durable membership/folder/provider revocation, and pending-open cancellation. The desktop coordinator must supervise them beside actual output. Native coordination/integration, FFmpeg fallback, synchronization, downloads, operating-system controls, platform packaging/signing, and acceptance remain unfinished.

Private bootstrap uses a one-use random ticket, redirects to `/library`, and sets an HttpOnly SameSite process cookie. Exact Host/Origin checks gate every local route before ordinary account authentication. Navigation/new windows cannot escape the local origin. Private query extraction errors are sanitized before Axum can render or trace submitted fields. The existing Lucide mark was exported as the mandatory PNG icon; logo regeneration remains a separate unchecked backlog item.

The server exposes an embeddable lifecycle without global logging initialization. Its owned supervisor retains indexing and HTTP connection tasks after observer cancellation. Shutdown closes the listener, drains HTTP for five seconds, then cancels and joins remaining connections. Core receives a cooperative scan stop, cancels only filesystem/media waits, completes write transactions, preserves verified source availability, and requeues interrupted work. Command permits are held until child kill/wait and private-input cleanup finish. The desktop lifecycle retains its library claim until that cleanup ends; repeated Tauri exit requests remain blocked until completion. Operating-system filesystem threads still retain their own handles/permits if a syscall stalls.

Run `scripts/verify.sh` and `scripts/check-desktop.sh` sequentially. The desktop profile uses `/build/desktop-target`; normal tools use `/build/target`. Compiler jobs are capped at two after overlapping linkers exhausted Docker memory. The GUI check uses a nonroot user, owned temporary XDG directories, synthetic WAV, an actual window manager, and a clocked PulseAudio null sink. It exercises setup, Settings folder selection, indexing, real WebKit decoding, navigation continuity, saved-account/library reopening, IPC denial, and joined shutdown. This does not prove physical output or native playback. See docs/desktop.md for ownership and limits.
